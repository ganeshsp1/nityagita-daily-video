# Security

This repo runs scheduled jobs that post to live YouTube, Instagram, Facebook and Threads accounts using repository secrets.

## Reporting a vulnerability
Please **don't open a public issue**. Report it privately through [GitHub's private vulnerability reporting](https://github.com/ganeshsp1/nityagita-daily-video/security/advisories/new) instead. Examples:
- a way for a pull request or fork to read secrets or trigger posting,
- a token or other secret exposed in code, logs, releases or history.

You'll get a reply as soon as possible, and leaked tokens will be revoked right away.
